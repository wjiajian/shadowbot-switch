---
name: shadowbot-flow-edit
description: Read, edit and verify a workflow in the current ShadowBot application.
---

Use the available `studio-mcp` tools to identify the app and flow. Read the current blocks or code before deciding how to make a change. Read the relevant block detail from the ShadowBot knowledge base before editing blocks with unfamiliar parameters. The bundled references are under `Resources/Copilot/knowledge/visual-blocks` in the ShadowBot installation.

Apply only the requested change through the matching flow-edit tool. Read the affected flow again to verify the result. Report which flow and blocks changed and identify any verification that still needs a run.
